# 今日どこ行く？

家族で週末のおでかけ候補を探す、スマホ対応のWebアプリです。
HTML・CSS・JavaScriptで作り、開発サーバーとビルドにViteを使っています。データベースやAPIキーは不要です。

## はじめかた

Node.js 22.12以上（この環境は24）で、リポジトリ内から実行します。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

通常のPCでは `npm ci` だけでもインストールできます。開発サーバーが表示するアドレスをブラウザで開いてください。

```sh
npm test       # 条件検索のテスト
npm run build  # 公開用ファイルをdist/へ生成
npm run preview # ビルドしたアプリを確認
```

## ファイルと改良方法

- `index.html`：画面の構成と条件の選択肢
- `style.css`：色、レイアウト、スマホ対応
- `spots.js`：10件のサンプルデータと検索ロジック。スポットを増やすときは配列に追加します。
- `app.js`：検索ボタンの処理と結果カードの表示
- `tests/search.test.js`：検索条件の組み合わせのテスト

## 検索のルール

複数の条件をすべて満たすスポットを表示します。初期表示は全10件で、「候補を探す」を押すと選択中の条件で検索します。

- 雨：屋内のみ。晴れ・どちらでも：屋内と屋外の両方。
- 移動時間：車／電車ごとの片道所要時間が、選んだ上限以内。
- 予算：家族4人分の合計が上限以内。無料は0円のみ。
- 滞在時間：そのスポットが対応する時間と一致。`stays` の `2` は2時間、`4` は半日、`8` は1日。
- 子ども向け度：サンプルの5段階評価です。

スポットはすべて架空です。実際の料金・経路検索や天気予報との連携は行っていません。実在スポットに置き換える場合は、出発地点、人数、年齢、最新料金も考慮してください。
