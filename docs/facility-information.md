## 情報の確認方針

施設・自治体・公式観光ページの本文を確認した項目だけを登録した。取得済みの公式HTMLも利用し、出典・取得元のハッシュを記録した。検索結果の断片だけでは確定していない。施設ごとの根拠は [information-sources.json](information-sources.json)、登録差分は `catalog-information-data.json` にある。

移動時間は瑞江駅起点で根拠を確認できなかった追加施設に数値を付けていない。既存の計画用時間を維持し、画面には「瑞江駅からの目安」と明示する。料金・所在地・設備の不明値も維持する。滞在時間は、例えばトンデミ平和島の公式2時間利用枠に対応する値を補完した。

## 駐車場と表示

`parking` は available / type / freeMinutes / fee / capacity / note の6項目。無条件の最初の無料時間をfree-limitedにし、購入や映画利用を条件とする割引はpaidのnoteに記載。区画・曜日・季節で料金が変わる場合、単一のfeeに押し込まず補足で説明する。無料時間が区画や曜日で異なる場合は共通する最短時間と具体的条件を保存した。

カードは、選択タグ・専用設備・中カテゴリに対応するタグを優先し、選択タグが先頭4件から落ちないようにした。自由検索で一致したタグも優先する。条件一致ポイントは最大4項目。駐車場を指定した時は駐車場表示を強調する。施設名・所在地・移動時間・家族料金・天候・最新訪問日と回数は引き続き表示する。

詳細は、駐車場の有無、料金区分、無料時間、料金、台数、補足と最後の訪問日を追加表示。全タグ、カテゴリ、所在地、公式リンク、車・電車、家族料金と補足、天候、季節、滞在、キャンプ・釣り・サウナの各登録項目も確認できる。編集・JSON保存にも駐車場の新項目を対応した。

## 保存データの保護

revision 6時点の標準値を `catalog-information-baseline.json` に保存し、新しい標準値との差分を移行する。標準値と異なる手入力値を優先し、独自タグは保持する。手入力の駐車場補足があれば駐車場オブジェクト全体を保護する。主カテゴリが変更された施設には旧カテゴリ向けのタグを補完しない。

お気に入り・履歴・ユーザー登録・非表示IDは保持し、非表示施設も非表示のまま情報だけを更新する。移行前後のデータは検証してから保存する。旧標準値と全く同じ値に編集した場合は、過去の編集記録がないため意図を判別できない。
