# 検索分類の修正（catalogRevision 6）

対象は検索不具合のみ。350件の固定ID、既存UI、ユーザー登録、思い出、お気に入りを維持する。

## 原因と対応

- ショッピング48件が「施設タイプ」のみに分類され、「買い物」「遊ぶ」が欠落していた。施設側の分類を補完した。検索のAND/OR、未確認値の扱いは変更していない。
- taxonomyに定義された中カテゴリ・タグが、施設データの有無によらず選択できた。現在の条件に対する実検索件数を表示し、0件の未選択項目をdisabledにした。選択済みの項目は0件でも解除できる。
- 保存済み固定スポットは改訂時にも分類が更新されなかった。revision 5の分類を基準に、新規補完分だけを追加する。主カテゴリを変更した施設は補完しない。旧タグの意図的な削除、独自タグ、その他の編集値、登録施設、非表示状態、履歴・お気に入りは保持する。非表示施設も非表示のまま分類を補完する。
- 買い物タグの候補から「アウトドア用品」が漏れていたため、明示したタグ一覧に修正した。施設の確認済みタグがない選択肢はdisabledになる。
