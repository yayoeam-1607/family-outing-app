# 350件カタログ・保存形式version 3

既存250件の固定IDを維持し、ユーザー提供の100候補を50件ずつ2バッチで追加しました。合計350件、固定ID・名称の重複なし、改訂5、保存形式version 3です。

今回はWeb検索を行っていません。既存250件の前回確認記録は [調査記録](catalogue-sources.md) / [根拠JSON](catalogue-evidence.json) に保管しています。追加100件は提供された名称・施設種別だけを使用し、所在地・営業状況・公式サイト・料金・時間・設備は未提供のため不明です。350件すべてを今回公式確認したという意味ではありません。

旧資料から駐車場9件・デイキャンプ等・サウナ4件の明記された情報を再利用し、根拠を [v3再利用記録](v3-reused-facts.json) に保存しました。季節は依頼文のタグとの関連によるおすすめで、営業期間を意味しません。子どもの入浴条件からサウナ利用条件は推定していません。既存3件の仮予算は新検索では不明としています。

検索は10大カテゴリ → 中カテゴリ → タグ、自由検索、時間範囲、予算上下限、駐車場、天候、滞在、季節、地域、未訪問、有名スポットに対応。キャンプ・釣り・サウナの専用条件は必要な時だけ表示します。

通常操作は非表示で、施設を保管し、お気に入り・思い出を保持します。年別サマリーと月別タイムラインは保管施設も含みます。version 1 / 2から移行し、移行前JSONを初回のみbefore-v3へ保管。ユーザーの追加・編集・非表示状態を維持します。

詳細な件数は [集計JSON](catalogue-summary.json)、自動テストとブラウザ確認は [検証記録](validation.md)、仕様と起動方法は [README](../README.md) を参照してください。
