# 実在施設カタログの登録状況

2026年10月11日、公式施設案内で確認済みの100施設を `catalog.js` に登録。`catalogReady` は true、カタログ改訂は1、保存データversionは2です。

公式情報の根拠は [施設別の調査記録](catalogue-sources.md) と [確認記録JSON](catalogue-evidence.json) に記載しています。施設ごとの参照URL・確認日・取得原本ハッシュを残しました。施設の実在確認と、経路や予算など計画用の推定は区別しています。

長期休館中の日本科学未来館を除外。各施設の部分工事、予約条件、持込制限、3施設の仮予算をカードと調査記録に明記しました。

## 維持した機能

- 旧架空施設は通常候補から外し、ID・内容・お気に入り・訪問記録を保管。
- ユーザー登録施設、初期施設の編集内容と削除済みIDを維持。
- 最初の移行前のJSONを `family-outing-data-v1-before-v2` に退避し、再度の改訂で上書きしない。
- 旧JSONの復元、雨／移動手段／時間／予算／滞在／カテゴリ／テント／BBQの条件検索、近い順、おすすめ、未訪問・お気に入り・訪問履歴を維持。
- 未確認のテント・BBQを可／不可検索から除き、編集しても未確認のまま保存できる。

検証結果は [検証記録](validation.md) に記載します。
